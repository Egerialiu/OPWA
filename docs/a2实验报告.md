# A2 — Weather-Conditional Gate + Plan B2 单天气路由实验报告

> 版本: v1.0 — 2026-06-08
> 结论：A2 条件 Gate 无效（−0.25%~−0.91%），
> Plan B2 单天气 GPPI 在 fog 上无效（D-Enc −4.73%, DCP −2.89%）。
> 加性退化（rain）上 A1 +1.43% 是最佳结果。

---

## 一、实验概述

### 目标
1. **A2**：WeatherEncoder + ConditionalGate 是否能让每个样本得到差异化的门控策略？
2. **Plan B2**：单天气 GPPI 模块 + 路由是否能突破 A1 多天气天花板？

### 结果速览

| 方向 | 最佳结果 | 结论 |
|:-----|:--------|:-----|
| A2 v7a@500 | −0.25% | ❌ 条件 Gate 无收益 |
| A2 v7a@1000 | −0.91% | ❌ 过拟合 |
| GPPI-fog (D-Enc) | −4.73% | ❌ D-Enc 对 fog 无效 |
| GPPI-fog-DCP | −2.89% | ⚠️ DCP 好于 D-Enc 但仍负 |

## 二、A2 — Weather-Conditional Gate

### 2.1 架构

```
I_deg ──→ WeatherEncoder (150K) ──→ 32-dim embed
                                            │
                                   ConditionalGate (3K) ──→ (4, B) gate values
                                            │
D-Enc → proj → branch × g_i ───────→ injection into VAE Dec up_blocks
```

- WeatherEncoder：3-layer CNN + AdaptiveAvgPool + Linear head
- ConditionalGate：MLP(33→64→1) per layer, query with normalized layer index
- 完全端到端，无天气标签需求
- 总计新增 ~153K 参数

### 2.2 结果

| 实验 | 步数 | Rain Δ | Fog Δ | Overall Δ | Gate pattern |
|:-----|:----:|:------:|:-----:|:---------:|:-------------|
| **v7a@500** | 500 | −5.21% | +1.78% | **−0.25%** | [0.28, 0.31, 0.33, 0.36] 浅低深高 |
| **v7a@1000** | 1000 | −2.17% | −0.40% | **−0.91%** | [0.27, 0.41, 0.56, 0.70] 浅低深高 |

### 2.3 Gate 演化（训练日志，v7a@500）

```
Step  20: [0.269, 0.270, 0.270, 0.270]  ← 初始化 ~0.27
Step 100: [0.245, 0.250, 0.256, 0.261]  ← 刚开始分化
Step 300: [0.245, 0.251, 0.257, 0.263]  ← 浅降深升
Step 500: [0.279, 0.306, 0.334, 0.364]  ← 浅低深高
```

**v7a@1000 gate 演化：**
```
Step 500:  [0.279, 0.306, 0.334, 0.364]
Step 700:  [0.347, 0.469, 0.591, 0.700]  ← LPIPS 梯度推高深层
Step 1000: [0.269, 0.410, 0.564, 0.703]  ← 深层主导
```

### 2.4 诊断

1. **Gate pattern 始终"浅低深高"**：与 GPPI 论文的"浅高深低"完全相反。GPPI 证明浅层需要更多退化特征（细节修复），深层需保留语义（gate 低）。A2 条件 Gate 学到的反模式说明它捕获的是 LPIPS 损失的梯度偏置（深层 VGG 特征梯度更大），而非天气相关的分配策略。

2. **Per-sample 分化未出现**：虽然 gate 输出是 `(4, B)` 形状，但训练日志中 gate 均值没有明显的 batch 内分化。WeatherEncoder 学的 32-dim 嵌入对所有输入趋于相似。

3. **结论**：条件 Gate + 153K 额外参数不值得部署。A1 的静态 gate 更好。

## 三、Plan B2 — 单天气 GPPI + 路由

### 3.1 架构

```
I_input ──→ Weather Classifier (brightness ratio)
               │
         ┌─────┴──────┐
         │             │
    GPPI-rain     GPPI-fog     passthrough
    (A1 v6f-500)   (新训)      (clear/night)
         │             │
         └──────┬──────┘
                ▼
          I_restored → SegFormer → mIoU
```

### 3.2 GPPI-fog 实验

| 实验 | 分支源 | 步数 | branch参数量 | Raw | GPPI | Δ | Gate |
|:-----|:------:|:----:|:-----------:|:---:|:----:|:-:|:----:|
| **GPPI-fog** | D-Enc | 2000 | 1.76M | 37.95% | 33.22% | **−4.73%** | [0.11, 0.11, 0.14, 0.19] |
| **GPPI-fog-DCP** | DCP | 500 | 1.55M | 37.95% | 35.05% | **−2.89%** | [0.12, 0.12, 0.12, 0.13] |

**为什么 fog 上 GPPI 失败？**

```
Rain:  I = J + R_streaks        → D-Enc 可学"减去条纹"
Fog:   I = J·t(x) + A(1-t(x))  → 需要深度相关透射率 t(x)
                                   轻量 CNN 无法在 500 步内学到
```

D-Enc 的 Gate 值 [0.11, 0.11, 0.14, 0.19] 表明网络主动关停了分支。这不是训练失败，而是 D-Enc **正确地判断自己的特征没用**。

### 3.3 DCP 物理先验

DCPBranch 计算暗通道先验 $t(x) = 1 - \min_c\min_{\Omega}I_c(y)/A_c$，提供空间分布的雾浓度图。

- DCP 比 D-Enc 好 1.84pp（−4.73% → −2.89%）
- 物理先验减少了损害但逆转不了趋势
- Gate [0.12, 0.12, 0.12, 0.13] 仍然接近关停

**结论**：DCP 是更好的归纳偏置，但解决不了"fog 乘性退化需要深层结构修复，而分支注入在深层稀释了分割信号"的本质矛盾。

## 四、Plan B2 端到端评估

### 4.1 组件状态

| 组件 | 状态 | 备注 |
|:-----|:----|:-----|
| Weather Classifier (brightness ratio) | ✅ 可用 | ≥95% 准确 |
| GPPI-rain (v6f-500) | ✅ +1.43% | 有效 |
| GPPI-fog | ❌ −4.73%~−2.89% | 无效 |
| GPPI-night | ❌ 未训练 | 数据不足 |
| 路由 pipeline | ✅ 代码就绪 | `scripts/eval_planb2.py` |

### 4.2 端到端预期

由于 fog 子集（22/31 样本）占测试集多数，且 GPPI-fog 低于原始退化，Plan B2 端到端结果预计低于 raw baseline。
