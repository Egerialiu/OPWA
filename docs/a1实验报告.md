## 三、根因分析：梯度路由悖论

### 3.1 问题描述

Gate 参数位于 UNet **外部**（影响 skip 连接注入），但其梯度必须经过 UNet 全部 **反向传播** 才能到达：

```
Loss = MSE(z_0, z_clean)
  → ∂Loss/∂z_0 ≈ 2(z_0 − z_clean) / N    (N=4*64*64=16384, 梯度很小)
  → 乘以 1/√α (t=100: 放大 1.35x; t=200: 0.70x)
  → 乘以 ε_pred → UNet_output 的雅可比
  → **穿越 50-80 层 UNet (每层 matmul 衰减 0.8-0.95)**
  → 到达 skip 注入点 → gate × projection_features
  → 到达 gate_params
```

**计算结果**:
- 假设每层梯度保留 0.9，50 层后留存 = 0.9^50 ≈ 0.005
- gate_lr=1e-3 时，有效 gate LR ≈ 5e-6
- 2000 步 × 5e-6 = 0.01，与观察到的 0.0002-0.0005 变化一致

### 3.2 GPPI → OPWA 迁移假设的问题

| 维度 | GPPI (ResNet-50) | OPWA (SD-Turbo UNet) | 影响 |
|:----|:----------------|:--------------------|:-----|
| 主干参数量 | 25M | 865M (35x) | 反向传播路径长 5-8x |
| Gate 注入位置 | layer2-4 skip (浅层) | up_block[0-3] (deep) | 梯度路径更长 |
| 主干冻结比例 | 部分 | **全部 + LoRA(0.24%)** | 冻结层无 grad 但传播梯度，衰减更严重 |
| 训练方式 | 全部微调 | LoRA rank=4 injection | 适应容量小 |

**关键结论**: GPPI 的"branch + gate 在 ResNet-50 上有效" **不能直接迁移到 865M UNet + 冻结 + LoRA 的设置**。梯度衰减量级相差两个数量级。

## 四、v5 实验设计（当前运行）

### 4.1 两个对比方向

**方向 A: direct 模式 (GPU0)**
```
z_deg → UNet(t=1) → ε_pred → z_out = z_deg − ε_pred
Loss = MSE(z_out, z_clean)
```
- 完全无噪声调度，梯度路径最短
- UNet base 在 t=1 输出≈0（因为输入是 latent 而非 noise）
- 但 LoRA 修改 attention 后，UNet 输出不再为零 → 学习信号出现
- **gate_lr=0.1**: 即使梯度只有 0.005x 衰减，有效 LR = 5e-4

**方向 B: dual 模式 (GPU1)**
```
Primary:  z_deg → add_noise(t∈[50,200]) → UNet → denoise → z₀
Auxiliary: z_deg → UNet(t=1) → z_out = z_deg − ε_pred
Loss = MSE(z₀, z_clean) + 0.3 × MSE(z_out, z_clean)
```
- 两个路径共享同一组 LoRA + gate
- Gate 从两个路径接收梯度，相加增强
- 去噪路径提供主信号，直传路径提供 gate 短梯度

### 4.2 核心超参数

| 参数 | direct | dual |
|:----|:-------|:-----|
| gate_lr | **0.1** | **0.1** |
| forward_mode | direct | dual |
| timestep range | t=1 (固定) | t∈[50, 200] + t=1 (aux) |
| 预期每步时间 | ~1.5 steps/s | ~1.0 steps/s |
| 训练步数 | 2000 | 2000 |

### **重要纠正**

此前报告中的"LoRA 未注入"结论已过时。LoRA 注入已通过 forward-hook 方式修复（`opwa/models/lora.py`），v4-v5 训练均有 2.6M 可训参数（含 LoRA）。`@torch.no_grad()` 和 t=1 的 bug 也已修复。

## 九、架构层面的关键发现

### 9.1 梯度路由悖论（核心）

```
Gate 梯度必须穿过:
  MSE_loss → z_0 → denoising → ε_pred → UNet_out → [50-80层 UNet] → skip_gate
```

每层 matmul 保留 ~0.9 梯度 → 50 层后 0.005x。这是架构级限制。

### 9.2 "冻结 UNet + LoRA" 与 "分支注入" 的内在矛盾

- LoRA 改变了 UNet 内部 attention —— 靠近 UNet 输出端
- Gate 在 UNet skip 连接处 —— 靠近 UNet 输入端
- 冻结的 UNet 参数虽然不更新，但梯度仍然要经过它们反向传播
- LoRA(0.24%) 的信号穿过 865M 参数到达 gate 时已极度衰减

### 9.3 GPPI 迁移假设需要重新验证

GPPI 在 ResNet-50(~25M)上有效 ≠ 在 SD-Turbo UNet(865M)上有效。差异核心在于：
- 梯度路径长度 (10-15层 vs 50-80层)
- 可训参数占比 (100% vs 0.24%)
- 训练范式 (全量微调 vs LoRA 注入)

> **免责声明**: 当前 A1 实验尚未确认架构有效性。v5 双 GPU 实验（direct/dual + gate_lr=0.1）是判定"梯度路由是否能修复"的关键实验。若 gate 仍无法学习，需考虑拆除 stop-grad 或全量微调 UNet。
