# OPWA A1 实验报告

> 版本: v3.0 — 2026-06-08 更新
> A1 核心结论：VAE Decoder injection 架构在 rain 上达到 +1.43% mIoU，但梯度路由悖论导致 <2% 天花板。

---

## 一、实验概述

### 实验目标
验证 VAE Decoder injection (+ D-Enc + StaticGate + LoRA) 架构在 SD-Turbo 上对多天气分割的有效性。

### A1 核心发现

| 发现 | 证据 | 意义 |
|:-----|:-----|:-----|
| **梯度路由悖论** | Gate 在 50-80 层 UNet 外，梯度衰减 200x | 冻结 UNet + LoRA 下 Gate 几乎不可训 |
| **+1.43% 天花板** | v6f-500 在 rain 上 +1.43%，超过即过拟合 | 架构级限制 |
| **VAE LoRA 有害** | v6c = −8.5% | 修改 VAE latent 分布破坏分割 |
| **GAN 有害** | v6e = −3.4% | GAN 引入对抗噪声 |
| **噪声探测有效** | v6a noise_probe = +1.00% | 结构拓扑本身提供正则化 |

## 四、根因分析

### 4.1 梯度路由悖论

```
Gate 梯度路径:
  pixel_loss → I_rec → VAE Dec → z_out → UNet [50-80层] → injection → gate
                                  ↓
  每层梯度保留 ~0.9 → 50 层后 0.9^50 ≈ 0.005x
  gate_lr=5e-4 → 有效 gate_lr ≈ 2.5e-6
```

**根源**：GPPI 在 ResNet-50 (25M, 10-15 层) 有效，但 SD-Turbo UNet (865M, 50-80 层) 的梯度衰减使其失效。这是架构级限制。

### 4.2 Gate 演化三种模式

| 模式 | 门值 | 条件 | 结果 |
|:-----|:-----|:-----|:-----|
| **均匀融合** | ~0.50 各层 | D-Enc 有用 | ✅ +1.43% |
| **被关停** | <0.15 | D-Enc 无用 | ❌ -3%~-8% |
| **深层主导** | 浅层低、深层高 0.64+ | 过拟合 | ⚠️ -1.01% |

### 4.3 退化物理性质的影响

| 天气 | 物理模型 | 最佳 Δ |
|:-----|:---------|:------:|
| Rain | $I = J + R$ (加性条纹) | **+1.43%** |
| Fog | $I = J \cdot t(x) + A(1-t(x))$ (乘性散射) | **-1%~-4%** |

Lightweight D-Enc 能学"减条纹"但学不到"深度相关透射率估计"。这与超参数无关，是归纳偏置缺失。

## 五、问题总结

| 问题 | 影响等级 | 状态 |
|:-----|:--------|:-----|
| 梯度穿越 50-80 层 UNet 衰减 ~200x | 🚨 **核心瓶颈** | 架构级，无法修复 |
| GPPI (ResNet-50) 迁移到 SD-Turbo (865M) 不成立 | 🚨 **核心瓶颈** | 架构级，无法修复 |
| LoRA (0.24% 参数) 不足以补偿梯度衰减 | 🔴 **限制因素** | 设计约束 |

| VAE LoRA 破坏 latent 分布 → mIoU 崩盘 | 🚨 **已知有害** | 禁用 |
| GAN 引入对抗噪声 → 分割退化 | 🚨 **已知有害** | 禁用 |
