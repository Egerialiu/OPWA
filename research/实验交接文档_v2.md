### 透射率计算规格

```python
BETA = 3.0  # 固定，不做超参搜索

def compute_transmittance(depth_raw):
    """
    depth_raw: numpy (H, W)，Depth Anything V2 原始输出
    注意：DA v2 Small 输出是视差风格（值越大=越近），需反转
    """
    d_min, d_max = depth_raw.min(), depth_raw.max()
    if d_max - d_min < 1e-6:
        return np.ones_like(depth_raw) * 0.5
    d_norm = (depth_raw - d_min) / (d_max - d_min)  # [0, 1]
    d_distance = 1.0 - d_norm  # 反转：远景大、近景小
    t = np.exp(-BETA * d_distance)
    return t  # (0, 1]，远景 ~0.05，近景 ~1.0
```

**深度方向验证**：取图像上 1/3（天空）avg_depth 应 < 下 1/3（地面）avg_depth

## 二、实验 0 精确规格

### Conformal Prediction 设置

```
方法：Split Conformal Prediction
目标覆盖率：1 - α = 0.9（α = 0.1）
Nonconformity Score（像素级）：s(x,y) = 1 - softmax(logit)[y_gt]
范围：[0, 1]，越大越不确定
q_hat 计算：np.quantile(all_valid_scores_across_calibration_set, 0.90)
预测集：C(x_pixel) = {c : softmax(logit)[c] >= 1 - q_hat}
覆盖条件：GT 类别 ∈ C(x_pixel)
```

## 五、三个最容易跑偏的地方

### 1. 透射率方向错误
Depth Anything V2 Small 是**视差风格（值越大=越近）**，必须反转：`d_distance = 1.0 - d_norm`。
验证：上 1/3 天空区域的 t 值应明显小于下 1/3 地面区域。

### 2. Score 计算粒度
必须像素级：`score[i,j] = 1 - softmap[i,j, gt[i,j]]`，GT 索引 softmax。

### 3. 分辨率对齐
SegFormer 输出 logits (B,19,H/4,W/4) → resize 到 GT 原图尺寸
Depth Anything 深度图 → resize 到 GT 原图尺寸
**两图尺寸必须一致再做像素级匹配！**

## 六、常用错误预防（速查表）

| 错误 | 正确做法 |
|:----|:--------|
| GT=255 参与计算 | 所有像素计算前加 `valid_mask = (gt != 255)` |
| 数据泄露：用 foggy 图做校准 | 校准集只用 Cityscapes 晴天 val |
| GPU OOM | 逐张推理，结果累计到 CPU numpy |
| mean_set_size≈19 | 检查 q_hat 是否过大；正常应在 1-5 |
| Foggy 文件名含 _foggy_beta_0.02 | GT 路径去掉该后缀 |
