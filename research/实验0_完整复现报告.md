### 3.3 透射率计算

```python
BETA = 3.0  # 固定，不做超参搜索

def compute_transmittance(depth_raw):
    d_min, d_max = depth_raw.min(), depth_raw.max()
    if d_max - d_min < 1e-6:
        return np.ones_like(depth_raw, dtype=np.float32) * 0.5
    d_norm = (depth_raw - d_min).astype(np.float32) / (d_max - d_min)
    d_distance = 1.0 - d_norm       # 反转：视差→深度风格
    t_map = np.exp(-BETA * d_distance)  # Beer-Lambert
    return t_map
    # 输出范围 (0, 1]：远景 ~0.05，近景 ~1.0
```

深度方向已验证：5 张 foggy 图的上 1/3（天空）t 均值 0.05-0.09，下 1/3（地面）t 均值 0.40-0.52，**方向正确**。

## 4. CP 设置

| 参数 | 值 |
|:-----|:-----|
| 方法 | Split Conformal Prediction |
| 目标覆盖率 (1-α) | **0.90**（α = 0.1） |
| Nonconformity Score | `s(x, y) = 1 - softmax(logit)[y_gt]`（像素级） |
| Score 范围 | [0, 1]，越大越不确定 |
| q_hat | `np.quantile(all_scores_on_calibration, 0.90)` |
| 预测集 | `C(x) = {c : softmax[c] >= 1 - q_hat}` |
| 覆盖条件 | `y_gt ∈ C(x)` ⇔ `score <= q_hat` |

---

## 5. 逐像素推理流程（伪代码）

```
for each test image (foggy):
  1. Image.open() → SegFormer processor → model → logits
     → F.interpolate((1024,2048)) → softmax → probs (1024,2048,19)
  2. cv2.imread() BGR → Depth Anything infer_image() → depth_raw
     → compute_transmittance() → t_map → cv2.resize((2048,1024))
  3. match_gt() → load_gt_label_ids() → gt (1024,2048), train IDs
  4. valid_mask = (gt != 255)
     for each pixel (i,j) where valid:
       score = 1 - probs[i,j, gt[i,j]]
       covered = (score <= q_hat)
       set_size = sum(probs[i,j] >= (1 - q_hat))
       bin = np.digitize(t_map[i,j], BIN_EDGES) - 1  # 0..4
       accumulate: pixel_count[bin]++, covered_count[bin] += covered,
                   score_sum[bin] += score, set_size_sum[bin] += set_size
```

## 6. Bin 定义

```python
BIN_EDGES = [0.0, 0.20, 0.40, 0.60, 0.80, 1.01]
BIN_NAMES = [
    "bin0_t0.00_0.20",   # 浓雾区（预期 Coverage Collapse）
    "bin1_t0.20_0.40",
    "bin2_t0.40_0.60",
    "bin3_t0.60_0.80",
    "bin4_t0.80_1.00",   # 清晰区
]
```

每个 Bin 计算：
- `pixel_count`：像素总数
- `covered_count`：GT 被预测集覆盖的像素数
- `coverage_rate = covered_count / pixel_count`
- `gap = max(0, 0.90 - coverage_rate)`
- `mean_set_size = sum(|C(x)|) / pixel_count`
- `mean_score = sum(score) / pixel_count`

## 10. 注意事项

1. **GT 映射**：Foggy Cityscapes 无独立 GT，使用 Cityscapes gtFine，文件名去掉 `_foggy_beta_0.02` 后缀
2. **Label 映射**：`gtFine_labelIds.png` 使用原始 Cityscapes 标签 ID（0-33），需要通过 LABEL2TRAIN 映射到 19 类训练 ID（0-18）
3. **深度方向**：DA-v2 Small 输出是视差风格（值大=近），必须在透射率计算中反转
4. **分辨率对齐**：SegFormer logits 输出 256×512 需 resize 到 1024×2048；DA-v2 深度图也需 resize 到 1024×2048
5. **有效像素过滤**：同时排除 `gt==255` 和 `gt>=19`（映射为 ignore 的原始标签）
