# 给执行模型的完整实验交接文档

## ⚠️ 最重要的前置声明（必须第一条给执行模型看）

> **本实验的唯一目的是验证"Coverage Collapse 现象是否存在且显著"。不是提升 mIoU，不是跑排行榜，不是复现 OPWA。所有代码决策都服务于这一目标。如果实验 0 的缺口 < 10pp，后续所有实验停止，等待人工决策。**

## 一、环境与数据规格（不可随意替换）

### 模型

- **分割模型**：`SegFormer-B0`，使用 HuggingFace 官方权重 `nvidia/segformer-b0-finetuned-cityscapes-1024-1024`
- **模型状态**：**完全冻结**，`model.eval()`，`torch.no_grad()`贯穿所有推理
- **透射率估计**：`Depth Anything V2`（Small 版本），**仅用于估计相对深度然后转换为透射率，不做深度绝对值使用**

### 数据集（按优先级）

```
Priority 1: Foggy Cityscapes（合成雾，有 GT，最稳定）
  - 版本：beta=0.02（最浓雾）
  - 分辨率：原始 2048×1024
  - 划分：val set（500张），不用 train set
  - GT：19类语义分割标签（Cityscapes 标准）

Priority 2: ACDC Fog（真实雾，有 GT）
  - 子集：fog，val split（106张）
  - 分辨率：1920×1080

校准集（Calibration Set）：Cityscapes 晴天 val set 前 250 张
测试集：Foggy Cityscapes val set 全部 500 张
```

### 透射率计算规格

这是最容易跑偏的地方，必须精确指定：

$$t(x) = \exp(-\beta \cdot \hat{D}_{norm}(x))$$

其中：
- $\hat{D}_{norm}(x)$：Depth Anything V2 输出经 min-max 归一化到 $[0,1]$ 的深度图
- $\beta = 3.0$（固定，不做超参搜索）
- 归一化**按图像级别**做，不是按数据集全局做
- 透射率 $t(x) \in (0, 1]$，值越小表示雾越浓

### Depth Anything V2 输出方向说明

| 属性 | 说明 |
|:----|:----|
| 输出风格 | 视差风格（disparity），值越大表示**越近** |
| 与常见深度模型差异 | 大多数深度模型输出"值越大越远"，Depth Anything V2 Small 相反 |
| 对透射率的影响 | 需要反转：`d_distance = 1.0 - d_norm`，使"远景值大、近景值小" |
| 验证方法 | 取图像上1/3区域(天空/远景)和下1/3区域(近景地面)，上1/3的depth归一化后均值应该 < 下1/3 |
| 错误模式 | 若透射率变为"近景低、远景高"，说明方向未反转 |

## 二、实验 0 的精确规格（阻塞性实验）

### Conformal Prediction 设置

```
方法：Split Conformal Prediction（最标准版本）
校准集：Cityscapes 晴天 val 前 250 张（作为 calibration set）
目标覆盖率：1 - α = 0.9（即 α = 0.1）
Nonconformity Score：像素级，s(x,y) = 1 - softmax(logit)[y_gt]
  即：GT 类别对应的 softmax 概率的补数
  范围：[0, 1]，越大表示越不确定
Threshold：q_hat = np.quantile(all_scores, 0.9) on calibration set
预测集：C(x) = {c : softmax(logit)[c] >= 1 - q_hat}
```

### 分层评估规格

```
透射率分5个Bin（边界固定，不可调整）：
  Bin 0: t ∈ [0.00, 0.20)  ← 浓雾区，预期 Coverage Collapse
  Bin 1: t ∈ [0.20, 0.40)
  Bin 2: t ∈ [0.40, 0.60)
  Bin 3: t ∈ [0.60, 0.80)
  Bin 4: t ∈ [0.80, 1.00]  ← 清晰区，预期接近 90%

每个 Bin 计算：
  1. pixel_count：该 Bin 内的像素总数
  2. covered_count：GT 类别在预测集 C(x) 内的像素数
  3. coverage_rate = covered_count / pixel_count
  4. gap = 0.9 - coverage_rate（正值=未达标，负值=超额覆盖）
  5. mean_set_size：该 Bin 内 |C(x)| 的平均值
  6. mean_score：该 Bin 内的平均 nonconformity score

注意：忽略 GT = 255（ignore label）的像素
注意：每张图独立计算透射率，Bin 分配按像素级别
```

## 三、执行顺序与依赖关系

```
Step 1: 验证模型加载正确性
  → 在 Cityscapes 晴天 val set 上跑 mIoU
  → 预期：≥ 76%（若 < 70% 说明权重加载错误，停止）

Step 2: 验证透射率计算
  → 取 5 张 Foggy Cityscapes 图像可视化透射率图
  → 预期：远景/天空区域 t < 0.3（偏蓝/深色），近景 t > 0.7（偏白/浅色）
  → 若透射率图完全均匀或反向，检查 β 值和深度归一化方向

Step 3: 跑 Split CP 校准
  → 在 Cityscapes 晴天 val 前 250 张上计算 q_hat
  → 验证：校准集覆盖率应在 [0.88, 0.92] 之间
  → 若不在此范围，检查 nonconformity score 计算

Step 4: 跑分层评估（实验 0 主体）
  → 在 Foggy Cityscapes val 500 张上推理
  → 输出 exp0_results.json
  → 触发决策树

Step 5: 仅当决策树通过后，继续实验 1-3
```

## 四、三个最容易跑偏的地方

### 跑偏点 1：用错数据集的 split

Cityscapes 的 train/val/test 分区**必须严格分开**：
- 校准集只能用 **val set** 的前 250 张
- 测试集用 **Foggy Cityscapes** 的独立 val set（500张）
- **绝对不能**用 train set 做校准，会导致 data leakage，覆盖率虚高

### 跑偏点 2：透射率方向错误

Depth Anything V2 默认输出的深度值**值越大表示越近**（视差风格）。需要验证：

```
检验方法：取一张 Foggy Cityscapes 图像
期望：天空/远景像素的 depth 归一化值 < 近景像素的 depth 归一化值
验证：取图像上 1/3 区域 avg_depth_norm vs 下 1/3 区域 avg_depth_norm
若上 > 下（即天空更大）：说明模型输出已经是"深度"风格，不需要反转
若上 < 下（即天空更小）：说明是视差风格（Depth Anything V2 Small），需要反转
最终透射率：近景应接近 1.0，远景/浓雾区应接近 0.0
```

### 跑偏点 3：Nonconformity Score 的计算粒度

CP 的 score 必须是**像素级**，不是图像级：

```
错误做法：对整张图的 mIoU 计算 score → 这是图像级 CP，失去空间分辨率
正确做法：对每个像素 (i,j)，score(i,j) = 1 - softmax(logit[i,j])[GT[i,j]]
然后 q_hat = 90th percentile of all valid pixel scores across calibration images
```

### 跑偏点 4：分辨率对齐

```
SegFormer 输出 logits 尺寸 (B, 19, H/4, W/4)，需要双线性插值回原图尺寸
Depth Anything 输出深度图 H×W（与输入一致），需要 resize 到 GT 尺寸
最后 softmax_map 和 t_map 必须在 GT 的原始分辨率上对齐
```
