## 三、实验 0 执行流程（四步串行）

### Step 1：模型加载验证

**代码模块**：`model_loader.py` + `run_experiment_0.py`

```
1. 加载 SegFormer → nvidia/segformer-b0-finetuned-cityscapes-1024-1024
   └─ 修改路径：统一用 /root/opwa_v3 替换 /OPWA_v3
2. 加载 Depth Anything V2 Small
   └─ repo 路径: /root/opwa_v3/Depth-Anything-V2/
   └─ 权重: /root/opwa_v3/checkpoints/depth_anything_v2_vits.pth
3. SegFormer 验证：Cityscapes 晴天 val 取 5 张推理
   └─ 目测 softmax argmax 结果有色块（道路/建筑/天空）
   └─ 可选：跑 mIoU（预期 ≥ 76%）
4. Depth Anything 验证：输出方向检查
   └─ 取 1 张 foggy 图，上 1/3 vs 下 1/3 depth_raw 均值比较
   └─ 确认是视差风格（上 < 下）还是深度风格（上 > 下）
5. 汇报结果 → 等待确认
```

### Step 2：透射率方向验证

**代码模块**：`transmittance.py` + `visualization.py`

```
1. 取测试集前 5 张 foggy 图
2. 每张计算 depth_raw → t_map
3. 生成 exp0_transmittance_vis.png
4. 汇报：近景（下 1/3）t 均值 vs 远景（上 1/3）t 均值
5. 预期：近景 t > 远景 t（近景 ~0.8-1.0，远景 ~0.05-0.3）
6. 汇报结果 → 等待确认
```

### Step 3：CP 校准

**代码模块**：`calibration.py`

```
1. 校准集：Cityscapes 晴天 val set，字母序前 250 张
2. 逐张推理，收集所有有效像素（gt != 255）的 score = 1 - softmax[gt]
3. q_hat = np.quantile(all_scores, 0.90)
4. 校准集覆盖率 = (score <= q_hat).mean()
5. 验证覆盖率在 [0.88, 0.92] 内
6. 若不在此范围 → 停止汇报
7. 汇报结果 → 等待确认
```

### Step 4：分层覆盖率评估（主体）

**代码模块**：`inference.py` + `evaluation.py` + `visualization.py` + `decision_tree.py`

```
1. 测试集：Foggy Cityscapes val 全部 500 张
2. 每张图：
   a. 原始图像 → SegFormer → softmax → resize 2048×1024
   b. 原始图像 → Depth Anything → t_map → resize 2048×1024
   c. 加载 GT（去掉 _foggy_beta_0.02 后缀匹配）
   d. 逐像素判断：有效？Score？Covered？所属 Bin？累计
3. 全局 rollup → 5 个 Bin 的 coverage_rate/gap/mean_set_size
4. 生成 3 张图
5. 输出 exp0_results.json
6. 触发决策树
```

    # 1. SegFormer 推理

    with torch.no_grad():
        logits = model(**inputs).logits  # (1, 19, 256, 512) = H/4 × W/4
    logits = F.interpolate(logits, size=(1024, 2048), mode="bilinear", align_corners=False)
    probs = F.softmax(logits, dim=1)  # (1, 19, 1024, 2048)

### 5.2 透射率计算（transmittance.py）

```python
BETA = 3.0

def compute_transmittance(depth_raw):
    d_min, d_max = depth_raw.min(), depth_raw.max()
    if d_max - d_min < 1e-6:
        return np.ones_like(depth_raw) * 0.5
    d_norm = (depth_raw - d_min) / (d_max - d_min)
    d_distance = 1.0 - d_norm  # 反转（视差→深度风格）
    t = np.exp(-BETA * d_distance)
    return t

def verify_depth_direction(depth_raw):
    """Return (upper_avg, lower_avg) for direction verification"""
    H, W = depth_raw.shape
    upper = depth_raw[:H//3, :].mean()
    lower = depth_raw[2*H//3:, :].mean()
    return upper, lower  # 视差风格：upper < lower
```

### 5.3 校准集文件选取（data_utils.py）

```python
import os, glob

def get_calibration_files(cityscapes_root, split="val"):
    """
    Cityscapes val: frankfurt (267) + lindau (59) + munster (174) = 500
    字母序排序后取前 250
    """
    pattern = os.path.join(cityscapes_root, "leftImg8bit", split, "*/*.png")
    all_files = sorted(glob.glob(pattern))
    return all_files[:250]

def get_test_files(foggy_root, split="val"):
    """Foggy Cityscapes val: 全部 500 张"""
    pattern = os.path.join(foggy_root, "leftImg8bit_foggy", split, "*/*_foggy_beta_0.02.png")
    return sorted(glob.glob(pattern))

def match_gt(foggy_path, cityscapes_root):
    """Foggy 路径 → Cityscapes GT 路径"""
    gt = foggy_path.replace("_foggy_beta_0.02", "")
    gt = gt.replace("leftImg8bit_foggy", "gtFine")
    gt = gt.replace("leftImg8bit", "gtFine_labelIds")
    gt = gt.replace("/foggy_cityscapes/", f"/{os.path.basename(cityscapes_root)}/")
    return gt
```

## 七、验证点速查

| 检查项 | 预期值 | 失败处理 |
|:-------|:-------|:---------|
| SegFormer mIoU | ≥ 76% | 权重错误，停止 |
| 深度方向：上 vs 下 | 上 < 下（视差） | 调整 d_distance 逻辑 |
| 校准集覆盖率 | [0.88, 0.92] | score 计算错误 |
| bin0_pixel_ratio | ≥ 0.05 | 透射率计算有误 |
| mean_set_size | 1-5（非 19） | q_hat 过大 |
